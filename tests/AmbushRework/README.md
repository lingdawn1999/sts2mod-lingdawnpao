# 埋伏重做回归检查

先在项目根目录编译模组，再运行测试：

```powershell
dotnet build -c Debug --no-incremental
dotnet run --project tests/AmbushRework/AmbushRework.csproj
```

测试分支在上述两条命令上都加 `-p:Sts2Ref=beta`。两次运行使用对应分支的实际游戏参考程序集和模组 DLL。

覆盖：不同名去重、首次触发顺序、升级替换、记录快照、清空、伏兵/磨爪的生产结算循环，实际卡牌基础及升级数值、重复涨费与复制牌费用、免费埋牌额度与卡面刷新通知，连环爪的叠层减费、费用下限、牌类型和持有者过滤，以及群攻目标、空区出牌、非循环死亡状态和野生狗奶专用视觉补丁的分支匹配。

这些是无场景的托管代码检查；不启动游戏、不读写存档。完整的战斗动作、界面、伏兵/连扑联动和联机仍需游戏内验证。
